# Ambiente: DB_PATH=:memory: e sem TELEGRAM_BOT_TOKEN.
# O ciclo completo (sem flag) nao foi executado: exige um provedor de IA acessivel.
# Neste ambiente o feed "Hacker News" recusou a conexao (ECONNREFUSED); a linha
# abaixo mostra o isolamento de falha por feed, nao um erro do kit.

$ DB_PATH=:memory: bun run example -- --ingest

$ DB_PATH=:memory: bun run example -- --digest

# Versao 0.5.0, 2026-11-10. Banco em arquivo (DB_PATH apontando para um .db),

$ bun run example -- --ingest

# Segunda coleta logo em seguida: tudo ja estava gravado.
$ bun run example -- --ingest

# Sem Ollama em localhost a IA falha e o digest cai para a lista bruta.
# Com --dry-run nada e enviado nem marcado (saida cortada apos o cabecalho).
$ bun run example -- --digest --dry-run
[digest] IA falhou (TypeError: ECONNREFUSED: Unable to connect. Is the computer able to access the url?) — enviando lista bruta
[digest] dry-run: nada enviado, itens continuam pendentes
